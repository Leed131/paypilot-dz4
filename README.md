## Запуск

set_hash: `67ca1d4fe79f`. Поточний loader має _compile_invariants
(blob f55a92bff06b5365e1819acd8aa7a1399f58b735).
Поруч мають бути l05 (офіційний кіт), paypilot-stand-shared (локальний стенд) і цей репозиторій.
Якщо назви папок інші, задайте свій STAND_DIR. Стенд і кіт окремо не здаються.

Із кореня цього репозиторію:

```bash
cp l05_dialogs.jsonl ../l05/sets/l05_dialogs.jsonl
cd ../l05
STAND_DIR=../paypilot-stand-shared docker compose run --rm eval --set l05_dialogs --gate release --dry-run
STAND_DIR=../paypilot-stand-shared docker compose run --rm eval --set l05_dialogs --gate release --profile clean --traces
STAND_DIR=../paypilot-stand-shared docker compose run --rm eval --set l05_dialogs --gate release --profile lesson-05 --traces
```

Не додавайте глобальний --summarize-after 2: він перевизначить контроль H04.
У кожному кейсі runs:5; --repeat 1 порушить протокол. Нові звіти раннер пише до l05/reports,
трейси — у підпапку traces того самого каталогу. Для здачі їх копіюють у reports/ та traces/ цього репозиторію.
Код завершення 1 на lesson-05 очікуваний: негативний контроль має виявити порушення.
